NewsReadingHelper

뉴스 기사 URL 하나를 넣으면 사실·맥락·인물·영향을 추려 1~2쪽 매거진 품질의 PDF 리서치 노트로 조판해 주는 Claude 스킬입니다.

ZIP 다운로드2.6 MB 설치 방법
Loader
00%
산출물 PDF + MD · A4 1~2쪽

Workflow작동 순서

3 phases
01

수집·리서치

기사를 가져와 사실·맥락·인물·연표·영향·불확실성으로 나눕니다. 기사만으로 부족한 배경은 최대 1~3회 검색으로 보충하고 출처를 남깁니다. 가져오기에 실패하면 지어내지 않고 본문을 요청합니다.

02

정보 구조 설계

렌더링 전에 report-outline.md를 먼저 씁니다. 사실·이름·숫자를 담지 않은 문장은 모두 쳐내는 밀도 규율을 적용합니다.

03

PDF 렌더링

HTML + CSS를 Playwright로 PDF화합니다. 2단 조판, 12~18mm 여백, 9~11pt 본문, 색 세 가지 제한, 섹션이 쪽을 넘지 않도록 하는 규칙을 따릅니다.

Report보고서 구성

7 sections
  • 01헤더한 문장 헤드라인, 출처, 발행일, 카테고리 태그
  • 02Executive summary3~5문장. 이 부분만 읽어도 상황을 알 수 있어야 합니다.
  • 03Key facts숫자·이름·날짜 중심의 하드 팩트. 숫자는 굵게.
  • 04Context왜 중요한지, 그 전에 무슨 일이 있었는지
  • 05Key players이름 · 역할 · 관련성 표
  • 06Impact & outlook단기·장기 영향, 전문가 시각, 주시할 지표
  • 07Sources원문 URL과 보충 출처. 타임라인·핵심 수치·인용 박스는 기사가 뒷받침할 때만 추가.

Triggers실행 문구

say it with a URL
  • 이 기사 PDF로 요약해줘
  • 이 뉴스로 원페이저 만들어줘
  • 리서치 노트로 정리해줘
  • 이 기사 executive brief 뽑아줘
  • summarize this article as a PDF

산출물 본문은 영어로 작성됩니다. 월스트리트 리서치 노트나 Economist 브리핑에 가까운 문체입니다. OFL 라이선스 폰트 54종이 동봉되어 별도 설치 없이 조판됩니다.

Install설치

zip only · no code

Claude.ai · 데스크톱 앱

설정 → 기능(Capabilities) → Skills에서 내려받은 news-reading-helper.zip을 그대로 업로드합니다. 압축을 풀지 않습니다.

Claude Code

압축을 풀어 스킬 폴더에 넣습니다.

~/.claude/skills/news-reading-helper/
├── SKILL.md
└── fonts/

zip 안에는 SKILL.md와 fonts/만 들어 있습니다. 실행 코드는 없고, PDF 렌더링은 Claude 실행 환경의 Playwright를 씁니다.
